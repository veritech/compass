# Compass

Compass is an android app that:
- show a compass, with heading
- shows the current latitude and longitude of the device
- shows the current altitude


It optionally can show
- the velocity of the device
- allows for adding a lat/lng to determine the bearing to that coordinate
- allows for breadcrumbs to be dropped at pre-defined intervals to create a GPX trail
- shows the number of GPS satelites


## Compatilbility
- Sourcecode should be Kotlin
- Works only the last two major versions of android
- Should work on a Samsung Galaxy A16 device
